# Local File Hub v0.1.3

v0.1.3 正式发布协同办公与文件安全能力。本次版本以 v0.1.1 为上一正式发布版本，收录 v0.1.2 实施的功能，并同步包版本与文档。

## 新增能力

- **文件与文件夹 ACL**：提供读取、下载、上传、编辑、Markdown 编辑和分享六类权限；支持按员工为具体条目单独授权，并沿目录链继承；管理员可指定权限管理员，管理员账号始终保留完整权限。
- **公开分享**：支持过期时间、访问次数上限、访问密码、撤销和只读访问；分享令牌以 SHA-256 摘要保存，文件夹分享限制在指定子树。
- **防泄密水印**：为图像和 PDF 预览/下载添加身份水印；公开分享内容增加分享者溯源水印；管理员可配置水印参数。
- **Markdown 工作流**：支持在线编辑 Markdown，并导出逐页带身份水印的 PDF。
- **安全加固**：认证接口限流、安全响应头、注册保护和高风险上传扩展名拒绝；下载及分享访问记录到活动审计。
- **管理功能**：新增全局活动审计与 CSV 导出、存储配额管理、水印配置，以及 SQLite 和对象文件备份脚本。
- **权限 UI**：新增权限链查看器、文件/文件夹权限设置和员工单独授权界面。

## 数据库与兼容性

- SQLite schema 迁移至 `user_version = 8`，启动时自动执行增量迁移；该值是数据库 schema 版本，不等同于应用版本 `0.1.3`。
- Node.js 要求为 `22.12+`。
- `npm run backup` 可执行在线一致性备份并归档对象文件。

## 安装与运行

```bash
npm install
npm run dev
```

生产环境部署要求与环境变量说明见 [README.md](../../README.md)。
