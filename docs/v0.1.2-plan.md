# v0.1.2 功能方案（协同办公 · 保密防泄密 · 公网部署 · 限时分享）

> 状态：**已实施，待人工测试**；实际 MD→PDF 实现采用 `markdown-it + pdf-lib`（未引入 puppeteer）。
> 基线：`dev-0.1.2` 分支；里程碑提交 `8457b5d`。本文保留原始方案作为实施范围对照。

---

## 1. 版本定位

项目定位为「**协同办公 + 保密防泄密的文件共享平台**」：

- **协同办公**：内部文件互通、MD 在线编辑、集中存储与检索；
- **安全保密防泄密**：同时防**内部人员泄密**与**外部人员泄密**；
- **向外部分享**：存在明确的向外部（无账号人员）分享场景，**分享必须有时效**（1小时内 / 1天 / 3天 / 7天 / 1个月 / 永久），可撤销、可审计、可溯源。

> **范围调整说明**：此前"分享仅权限维度、不做匿名公开分享链接"的决定被本需求推翻——**公开分享链接（匿名、限时、只读）纳入 v0.1.2**。

**已确认的设计决策**：
1. 权限粒度：**文件夹级继承**（子文件夹继承，根目录为默认策略）。
2. 水印实现：**动态叠加**（不改服务器上的原始文件，可随时调整/关闭）。
3. 部署形态：**公网部署**（VPS 或 NAS+隧道均可），HTTPS + 安全加固。
4. 外部人访问方式：**分享链接匿名访问**（限时/限次/可撤销，见第 4 章）；站内成员通过邀请码注册登录。
5. 防泄密：**内防 + 外防**双线（身份水印溯源、只读不可下载、分享溯源、全量审计，见第 3 章）。

## 2. 公网部署与安全加固

- 强制 HTTPS：Caddy / Nginx 反代模板，`docker-compose.yml` 增加可选 TLS 反代服务（Let's Encrypt）。
- Cookie：生产强制 `Secure`、保持 `SameSite=Strict`；`TRUST_PROXY` 文档化。
- **登录/注册/重置密码限流**：按 IP + 用户名固定窗口（如 5 次/分钟），`429`。
- **注册/邀请保护**：注册接口纳入限流；邀请码高熵（12+ 位随机）；可配置**关闭开放注册**（仅邀请注册）。
- **安全响应头**：CSP、HSTS、`X-Frame-Options`、`X-Content-Type-Options`、`Referrer-Policy` 生产默认开启。
- **上传白名单**：扩展名 + MIME 双重校验，默认拒绝 `.exe/.html/.js/.sh` 等；`image/*` 可选 `sharp` 重编码净化（防 SVG/HTML 注入投毒）。
- 会话：公网建议 `SESSION_TTL_HOURS` 缩短（如 12h），文档化。

## 3. 泄密防务体系（内防 + 外防，核心）

### 3.1 威胁模型

| 场景 | 风险 | 对策 |
|---|---|---|
| **内部人员泄密** | 员工下载/截图/导出后外传 | 身份水印溯源、只读不可下载、全量下载审计、最小权限 |
| **外部人员泄密** | 拿到分享链接的人二次转发/泄露 | 分享限时/限次/可撤销、分享溯源水印（定位到内部分享者）、访问全审计 |

### 3.2 身份水印（内部溯源）
- 所有服务端可视化输出叠加**浏览者身份水印**：`用户名 + 日期时间`（可含 IP 尾号/会话标识），管理员配置：
  - 图像预览与下载（sharp 合成）；
  - MD→PDF 导出（每页绘制）；
  - 文本/MD 网页预览（CSS 叠加水印层）；
  - 现有 PDF 下载（可选，pdf-lib 嵌入中文字体）。
- **防泄密的强约束在服务端输出**（下载/导出由服务端加水印，前端无法绕过）；浏览器预览 CSS 水印为威慑层，文档如实说明。

### 3.3 只读不可下载策略（内部最小授权）
- `read = true` 且 `download = false` 时：可浏览、可预览（水印版），**禁止下载与流式保存**（服务端强制，`403`）。
- 配合文件夹级 ACL（第 5 章）实现"密级目录可看不可拷"。

### 3.4 分享溯源水印（外部溯源）
- 分享链接输出的所有内容（预览/下载/导出）叠加**分享者身份水印**：`分享者用户名 + 链接短码 + 时间`。
- 外部泄密时可**定位到内部分享者**；撤销链接后立即失效。

### 3.5 全量审计（内 + 外）
- 只增不改的 `activity_logs`（已有表），新增动作：分享创建/访问/下载/撤销、权限变更、水印配置变更、MD 导出、下载（含用户+文件+大小）。
- 管理员全局审计页面 + CSV 导出（第 8 章）。

### 3.6 最小权限与会话安全
- 新用户默认无权限；邀请预设；文件夹级 ACL；管理员全权。
- 登录限流、会话失效（停用/改密即失效，已有）、公网缩短 TTL。

### 3.7 后续（不在 v0.1.2）
- 下载审批流、敏感目录标记、多因子认证、设备管理。

## 4. 公开分享链接（匿名 · 限时 · 只读 · 可撤销）

### 4.1 时效档位
创建分享时从固定档位选择，管理员可配置可用档位（如是否允许永久）：

```
1h  |  1d  |  3d  |  7d  |  30d  |  forever（永久）
```
- 到期自动失效；**永久链接**随时可手动撤销，且受管理员"允许永久"开关与审计约束。
- 附加限制（可选）：**访问/下载次数上限**；**访问密码**（可选，密码错误不返回任何文件信息）。

### 4.2 数据表 `shares`（`user_version` 5 → 6 一并迁移）
| 字段 | 说明 |
|---|---|
| `id` | 分享记录 UUID |
| `token` | 高熵短码（如 16 位随机，防枚举），唯一 |
| `file_id` | 指向 `files.id`（可指向文件或文件夹） |
| `kind` | `file` / `folder` |
| `created_by` | 创建者 user_id（溯源关键） |
| `expires_at` | 过期时间；NULL = 永久 |
| `max_accesses` | 次数上限；NULL = 不限 |
| `access_count` | 已访问次数 |
| `password_hash` | 可选访问密码哈希（scrypt） |
| `is_revoked` | 是否已撤销 |
| `created_at` / `last_access_at` | 时间 |

### 4.3 接口
**站内（需登录 + `can_share` + 目标文件 `read`）**
- `POST /api/share-links`：创建（fileId/kind、时效档位、可选次数、可选密码）
- `GET /api/share-links`：我的分享列表（管理员可看全部 + 撤销任意）
- `PATCH /api/share-links/:id`：重置时效/次数/密码、撤销、恢复
- `DELETE /api/share-links/:id`：删除记录

**公开（匿名，无需登录）**
- `GET /s/:token`：分享落地页（前端路由；校验存在/未撤销/未过期/次数未超/密码）
- `GET /api/public/shares/:token/info`：文件元数据（需密码时先验密码）
- `GET /api/public/shares/:token/download`：下载（服务端加水印，计次数、审计）
- `GET /api/public/shares/:token/stream`：预览流（图像/媒体/文本，水印版）

### 4.4 匿名访问页
- 只读：仅可预览与下载该分享指向的**单个文件/该文件夹子树**，不能登录、不能浏览站内其他目录、不返回内部路径/上传者（返回"分享者"仅以水印呈现）。
- 展示状态：已过期 / 已撤销 / 次数用尽 / 需密码。

### 4.5 安全与审计
- token 高熵防枚举；接口统一校验五要素（存在/未撤销/未过期/次数/密码）。
- 每次访问/下载：`access_count` 自增 + 写入审计（token、分享者、IP、UA、时间）。
- 外部输出全部带分享溯源水印；撤销即时生效（读取时校验 `is_revoked`）。

## 5. 文件夹级继承权限模型

### 5.1 权限维度（统一枚举）
| 权限 | 说明 |
|---|---|
| `read` | 浏览目录、查看元数据、在线预览（水印版） |
| `download` | 下载 / 流式播放（与原 read 拆分；false 时"可看不可拷"） |
| `upload` | 上传文件、新建子文件夹 |
| `edit` | 文件管理：重命名 / 移动 / 复制 / 删除 |
| `edit_md` | **MD 内容编辑**：仅对 `.md` 文件在线编辑与保存 |
| `share` | **创建/管理公开分享链接**（第 4 章） |

管理员始终全权。原用户表 `can_read/can_upload/can_edit` 转为遗留字段（DB 保留、授权不再读取）。

### 5.2 数据结构与迁移
- 新表 `folder_permissions`：`folder_id` PK（`files.id`；`'ROOT'` 为默认策略）+ 六维权限位 + `updated_by/updated_at`。
- `files` 表新增 `is_shared`（展示用，由分享链接功能驱动）。
- 迁移默认策略：`ROOT` = 对已登录用户全开，管理员随后按需收紧；实施时提供"默认收紧"配置开关。

### 5.3 生效规则
- 用户对文件夹 F 的生效权限 = 沿父路径向上找最近显式 ACL，`ROOT` 兜底；管理员忽略。
- 文件操作按所在文件夹生效权限判定；上传/复制按目标文件夹。
- 权限校验集中在服务端 `authz` 模块；防锁死（不能改掉自己对当前目录的管理权）。

### 5.4 接口与前端
- `GET /api/admin/permissions?folderId=`（读 ACL + 继承结果）、`PUT /api/admin/permissions`（设置/恢复继承）。
- 前端文件夹"权限设置"面板（权限矩阵 + 继承提示）；根目录可设默认策略；用户管理改为权限摘要展示。

### 5.5 已实施方案（v0.1.2 实际行为，`doc/PERMISSIONS.md` 为完整文档）
- **权限来源**：`folder_permissions` 提供目录 ACL；`users.can_read/can_upload/can_edit` 作为账号基线。ROOT 策略与账号基线取交集，最近的显式子目录 ACL 可按管理员配置覆盖基线；ACL 表缺失时账号基线作为兼容授权来源。
- **ROOT 默认策略**：迁移 `user_version` 6 → 7 时自动预置 `ROOT` 行（`open` 模式 = 站点策略矩阵全开，实际权限仍受账号基线约束；`tighten` 模式 = 仅读 + 下载），并写入 `app_config.folder_permissions_default_mode`；管理员可按需收紧或切换模式。
- **权限链解析优先级**：`admin`（全权）→ 最近显式目录 ACL → `ROOT` 策略与账号基线交集 → 无 ACL 表时账号基线兼容授权。
- **迁移幂等**：`user_version >= 7` 静默通过；`folder_permissions` 缺失则建表；`ROOT` 存在则不重复种子；`app_config` 值非 NULL 时不覆盖。
- **管理端扩展接口**（`/api/admin/permissions`）：
  - `GET /all`：所有已配置 ACL（含目录名）；
  - `GET /permissions-health`：健康检查（表存在性、ROOT、模式、计数、告警编码见 `doc/PERMISSIONS.md` 5.1）；
  - `GET /permissions-chain?userId=&folderId=`：指定用户-目标的完整权限链（逐跳显式 ACL、命中点、继承语义、生效权限）。
- **前端入口**：文件库页管理员按钮 **权限链**（PermissionChainViewer：用户选择 + 目标目录 + 健康检查 + 全量 ACL 表）；**目录权限**（FolderPermissionsDialog）内嵌 **查看权限链** 链接；用户管理对话框改为"默认权限（文件夹 ACL 未覆盖时生效）"。
- **影响**：ROOT `open` 不会提升原有受限账号的权限；管理员对具体子目录设置的显式 ACL 仍可按需覆盖账号基线。

## 6. 动态水印 + MD 转 PDF

### 6.1 管理员水印配置
- `app_config`（key-value）承载：`enabled`、`text`（支持占位符 `{username}` `{date}` `{time}`）、`opacity`、`position`（平铺/角落）、`font_size`、`color`、`angle`、`apply_to`（预览/下载开关）。
- 变更即时生效；可选按 `sha256 + 配置版本` 缓存结果。

### 6.2 图像水印（sharp）
- 预览/下载 `image/*` 服务端合成水印，不改原始对象；`svg` 转 png 后水印（同时消除内联 XSS）；限制输出像素防内存耗尽。

### 6.3 MD → PDF（实际实现：markdown-it + pdf-lib）
- `GET /api/files/:id/export-pdf`（需 `read+download`，仅 `.md/.markdown`）。
- 链路：md → `markdown-it`(GFM) → 结构化文本 → **每页身份水印** → `pdf-lib` 绘制 → PDF 附件。
- 当前轻量实现使用 pdf-lib 标准字体，中文渲染能力有限；渲染器接口化，后续可替换 Chromium + Noto Sans CJK。

### 6.4 水印作用范围矩阵
| 类型 | 预览 | 下载/导出 |
|---|---|---|
| 图像 | 身份水印 | 身份水印 |
| `.md` | CSS 水印层 | 原样下载；导出 PDF 每页身份水印 |
| `.txt`/代码 | CSS 水印层 | 原样 |
| `.pdf` | 浏览器预览 | 可选叠加（pdf-lib 嵌中文字体） |
| 音频/视频 | 流式播放不水印 | 原样 |
| 分享链接输出 | 分享者溯源水印 | 分享者溯源水印 |

## 7. 文件类型权威分类

服务端统一判定（`file-service` 单一入口 + 前端枚举一致）：

| 大类 | 扩展名（示例） | 预览 | 水印 | 编辑 |
|---|---|---|---|---|
| 文本 | `.md/.markdown/.txt/.log/.csv/.json/.xml/.yaml/.toml/.ini/.conf` | 纯文本/MD 渲染 | 有 | MD 在线编辑 |
| 文档 | `.pdf`（预览，可选水印）；`.doc/.docx/.xls/.xlsx/.ppt/.pptx/.odt`（仅下载） | 见左 | 可选 | — |
| 图像 | `.png/.jpg/.jpeg/.webp/.gif/.bmp/.avif/.svg` | 预览 | 有 | — |
| 音频 | `.mp3/.wav/.ogg/.m4a/.aac/.flac` | 流式播放 | 无 | — |
| 视频 | `.mp4/.webm/.mov/.mkv/.avi/.flv` | 流式（受限浏览器仅下载） | 无 | — |
| 压缩/其他 | `.zip/.7z/.rar/.tar.gz/.apk` 等 | — | — | — |
| 禁用(默认) | `.exe/.bat/.cmd/.sh/.html/.htm/.js/.ps1` 等 | 上传白名单拒绝，可配置 | — | — |

前端 `type` 筛选：`text/document/image/audio/video/other`。配置项 `ALLOWED_EXTENSIONS` / `BLOCKED_EXTENSIONS`。

## 8. 合并保留（配额 + 备份 + 全局审计）

- **管理员存储配额**：`PATCH /api/admin/users/:id` 启用 `storage_quota_bytes`（`>=0`，`0` 不限；不能低于已用否则 409）；列表返回 `storage_used_bytes`；用户管理对话框配额输入 + 已用展示。
- **备份脚本**：`scripts/backup.ts`（`npm run backup`）：better-sqlite3 在线 `backup()` + `objects/` 归档到 `BACKUP_DIR`（默认 `./backups`，时间戳目录），`PRAGMA integrity_check` + 保留最近 7 份；不含 `uploads/`。
- **全局活动审计**：`GET /api/admin/activity`（分页 + `userId/action/from/to`），前端"活动日志"面板 + CSV 导出；保留用户详情最近 50 条。审计动作覆盖第 3.5 章全部新动作。
